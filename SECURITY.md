# Security and data protection

This public repository is an **independent, synthetic demonstration**.

- No secrets, passwords, authentication tokens, real API endpoint configuration, customer IDs or employee records should ever be committed.
- Never commit private internal documentation, operational source code, real ASO reports, screenshots of actual audits or company-specific spreadsheets.
- There is no production integration. The project must not be connected to live eSocial services or real employee datasets.
- The mock receipts (`REC-DEMO-*`) and entities (`DEMO-*`, `Empresa Fictícia`) have no real-world meaning.
- CSV output is generated in your personal Google Drive, only when the export action is selected.
- If you reuse the example, keep it in a new spreadsheet and review the requested Google permissions.
- Confirm ownership and publication rights before publicly disclosing any code created in an employment or client context. This demo should not be confused with permission to publish original work.

If credentials or private data are ever added by mistake, remove them from Git history and rotate any exposed secrets before sharing the repository.
